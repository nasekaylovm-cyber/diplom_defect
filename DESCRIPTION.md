# Документация безопасного пайплайна для Open-Source проекта

## Выбор инструментов

### SAST (Static Application Security Testing)
**Выбранные инструменты:**
- **Bandit** - специализирован для Python, обнаруживает распространенные уязвимости
- **Semgrep** - мультиязычный анализатор с большим набором правил
- **Safety** - проверка уязвимостей в Python зависимостях
- **CodeQL** - продвинутый статический анализ от GitHub

### Security Checks
**Инструменты:**
- **Trivy** - сканирование образов и зависимостей
- **GitHub CodeQL** - дополнительный security анализ

### DAST (Dynamic Application Security Testing)
**Инструмент:** **OWASP ZAP**
- Автоматизированное сканирование работающего приложения
- Обнаружение runtime уязвимостей
- Интеграция с CI/CD
